# Korunan taslaklar

`desktop/beytarchiver_mobile.py`, önce `lan_transfer/beytarchiver_mobile/` altında
bulunan alternatif CustomTkinter masaüstü kaynağıdır. İçeriği değiştirilmeden
buraya taşındı. Mobil uygulamanın giriş noktası değildir; aktif masaüstü giriş
noktası kökteki `beytarchiver.py`, Flet giriş noktası `mobile/main.py` dosyasıdır.

Bu taslak üretim derlemesine ve test keşfine dahil edilmez. Burada bulunması
test edildiği veya aktif sürüm yerine kullanılabileceği anlamına gelmez.
